# Fxxking Work

上班的时候，打开菜单栏就能看到今天已经赚了多少。

Fxxking Work 是一个 macOS 菜单栏应用。它根据你的工资、工作时间和节假日安排，实时计算今天、本月和本年的收入。数据只保存在本机，不需要注册账号。

## 功能

- 菜单栏实时显示今日金额、今日进度、本月金额、本月进度或本年进度。
- 可设置工作日、上下班时间和午休；法定假日、周末和调休补班都会计入工作日计算。
- 支持税后估算，包括中国大陆的社保、公积金和累计预扣个税。
- 支持手动加班计时、1／2／3 倍时薪、13／14 薪和工资变更历史。
- 可设置账期截止日和发薪日，查看下次发薪时间及本账期已赚金额。
- 隐私模式会隐藏菜单栏和主面板金额，点击任意金额可统一查看，关闭面板、切换应用或 30 秒后恢复隐藏。
- 支持跟随系统、浅色、深色外观，以及简体中文、英文、法文、俄文和西班牙文。
- 支持开机启动和 GitHub 应用内更新。

## 下载

从 [Releases](https://github.com/cailish-0425/Fxxking_Work/releases/latest) 下载：

- `Fxxking_Work-macos-universal.zip`
- `SHA256SUMS`

解压后将 `Fxxking Work.app` 拖进「应用程序」。应用要求 macOS 14 或更高版本，同时支持 Apple Silicon 和 Intel Mac。

安装前可以校验下载文件：

```bash
shasum -a 256 -c SHA256SUMS
```

当前安装包使用 ad-hoc 签名，没有 Apple 公证。首次打开时，请按 macOS 的提示确认运行。

## 首次使用

第一次打开后，从菜单栏进入「设置」，填写月薪和作息时间即可开始计薪。

设置里还可以调整税后参数、加班、工资变更、发薪账期、隐私、外观和语言。旧版本留下的工资、作息、假日和语言设置会继续保留。

## 计薪方式

应用以月薪为基准：

```text
日薪   = 月薪 ÷ 当月工作日数
计薪秒 = 上下班时间扣除午休后的秒数
秒薪   = 日薪 ÷ 计薪秒
```

今日进度按已经过去的计薪时间计算，本月和本年按已赚金额占应发金额的比例计算。

加班需要手动开始和结束。上班日要等到下班时间之后才能开始，休息日可以直接开始。锁屏或熄屏期间暂停计时，每段最晚在开始后的下一个凌晨 2:00 自动结束。

有偿加班进入工资计算；无偿加班只显示一个参考倒扣金额，不改变实际工资、税基或账期收入。

## 税前与税后

税前模式按工资毛额显示。

税后模式只适用于中国大陆和人民币。它会按当前参数和工资历史估算全年累计预扣，计算社保、公积金、个税和预计到手金额。

税后金额是估算，不是公司实际发放记录，也不是报税结果。北京、上海提供参考参数；其他城市使用自定义参数。

## 数据与隐私

工资、加班、账期和其他配置只保存在本机，不会上传到服务器。

隐私模式默认隐藏金额。设置窗口中的金额保持可查看和编辑，方便配置。

法定假日数据来自 [wrfly/holidays](https://github.com/wrfly/holidays)。应用会缓存当年和次年的数据，断网时继续使用本地缓存。

## 开发

需要 macOS 14 或更高版本，以及 Xcode Command Line Tools。

```bash
git clone https://github.com/cailish-0425/Fxxking_Work.git
cd Fxxking_Work

./Scripts/run-checks.sh
python3 Scripts/check-localization.py
./Scripts/build-app.sh
```

`build-app.sh --zip` 会额外生成可分发压缩包，`--install` 会把应用复制到 `/Applications`。
